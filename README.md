# TodoSalud Web

Frontend público de Todo Salud C.A., reconstruido en React + Vite tomando como referencia visual y de contenido el sitio `rmdescartables.com`.

## Incluye

- Inicio
- Productos
- Contactanos
- Navegación responsive
- Vista mobile dedicada
- Assets responsive del sitio de referencia
- Integración con WhatsApp
- Configuración SPA para Vercel
- GitHub Actions para validar el build

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Repositorio privado de Taga Studios.
